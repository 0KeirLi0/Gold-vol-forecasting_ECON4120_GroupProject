# Instructions for AI agents

Before making changes that depend on project context, read [`.ai/README.md`](.ai/README.md) and recent entries in [`.ai/SESSION_LOG.md`](.ai/SESSION_LOG.md), then verify the current files and Git history.

Use the shared log to hand off meaningful decisions, findings, and cross-stage work to future agents and teammates:

- Append dated entries; do not rewrite or delete earlier history.
- Label items as decisions, findings, proposals, or open questions, and attribute decisions and evidence.
- Record relevant context, outcome, affected artifacts, limitations, and next action/owner when known.
- Do not invent team decisions, results, sources, or data requirements.
- Never store secrets, personal information, or restricted data in the log.

Follow the project workflow and stage handoffs in [`.github/copilot-instructions.md`](.github/copilot-instructions.md), and use [`GIT_WORKFLOW.md`](GIT_WORKFLOW.md) for shared Git changes. The log supplements, but does not replace, project documentation or implementation.
